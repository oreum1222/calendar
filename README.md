# [오름] 마감 캘린더

강사·조교가 폰으로 열면 **"내가 언제까지 뭘 해야 하는지"** 가 디데이 순으로 바로 보이는 학원 업무 마감 캘린더.
원장이 일일이 추적·독촉하지 않아도 마감과 미이행자가 스스로 드러나는 구조.

- **배포(GitHub Pages)**: https://oreum1222.github.io/calendar/
- **비밀번호 게이트**: 강사진 전용(기본 `74527697` — 운영 시 `CONFIG.password` 변경)

## 주요 기능
- 임박 리스트(기한 지남/오늘/이번 주/다가옴/완료) + 월간 달력, 반응형 2단
- 담당 체크리스트: 일정마다 담당 명단, 본인 PIN으로 자기 칸 체크 → `2/4 완료` 표시
- 필터: 담당(개인)·그룹(강사/조교)·구분(설명회/내신/교재/모고/행정/홍보)·상태
- 반복 일정(매주/매월) 자동 전개, 디데이 자동 계산, 독촉문구 복사
- 다크 테마(민트 강조), Noto Serif/Sans KR

## 파일
| 파일 | 설명 |
|---|---|
| `index.html` | 앱 본체(단일 파일). `CONFIG`에서 비번·시트주소·강사/조교 수정 |
| `Code.gs` | Google Apps Script 백엔드(PIN 검증 + 체크 기록) |
| `셋업_체크기능.md` | 구글시트 4탭(일정·강사·조교·체크) 만들고 연결하는 절차 |
| `[오름] 마감캘린더_시트양식.xlsx` | 바로 올려 쓰는 시트 양식(4탭, 실데이터 포함) |

## 데이터 연결
- 비워두면 **데모 데이터**로 동작.
- 구글시트 연동: `셋업_체크기능.md` 참고 → 시트 '웹에 게시 CSV' 또는 Apps Script 웹앱 주소를 `index.html`의 `CONFIG.sheetCsvUrl` / `CONFIG.apiUrl`에 입력.
